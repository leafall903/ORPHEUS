the existing NPC catalog, XML and base graph bundle. It preserves the associated
definition's own StatescriptComponent and ordered graph/schema rows, including
null slots. Child entity scripts never become controller initial scripts. A
controller definition does not inherit a caller's hero identity: hero/name stay
on the body association. Additional graph closure is extracted only when absent
from the base; cycles deduplicate, base references are reused and missing assets
remain explicit. Source hashes and the exact base fingerprint are retained.

all input directories;hardlinked output files are rejected. It never rewrites
