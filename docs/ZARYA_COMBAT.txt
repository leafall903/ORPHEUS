Implemented change
------------------
An active authored primary ModifyHealth State now consumes command time once per
activation and integrates the evaluated damage rate. It selects the nearest live
enemy with the existing historical body poses, checks static world obstruction,
and calls normal health/death/notice/stat handling. It cannot critically hit.
Body retirement drops its clock; repeated command consumption adds no damage.
No manual button-to-damage shortcut bypasses ammo or authored activation.

Reconstructed assumptions: eye-origin beam; expanded capsule intersection;
damage integrated over command time; instant target selection from current aim.
Native muzzle transforms, TrackRay output bindings, target acquisition/loss timing,
beam-specific armor rules and continuous hit-feedback cadence remain unaccepted.
Existing shared damage rules are used; this does not prove their retail fidelity.

Personal barrier and energy increment
------------------------------------
The active0244 personal-pet State now intercepts hostile damage before body pools.
Capacity is evaluated from0256/node0 (200 for the tested player profile). Each
activation has one server pool; re-presses cannot refill it. Exhaustion schedules
the authored parent duration to finish, which follows StopAbility and starts the
existing cooldown. Natural duration and cooldown remain authored State behavior.
The energy message comes from0242/node5; its existing expression adds20% of the
absorbed HP, caps100, and its States implement the observed subsequent decay.
The damage source is preserved in the authored message parameter0012.

Reconstructed policies: whole-body damage interception while the personal pet
State is active; the breaking damage event is entirely blocked; energy counts
only remaining barrier HP; exhaustion finishes the parent duration next script
step. These policies have behavior tests but no new native-server comparison.
This does not host a real pet entity, reproduce barrier volume intersection,
cleanse/control immunity, or prove cross-hero effects. Projected barrier stays open.
