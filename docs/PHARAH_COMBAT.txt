Focused shared fix
Explosive splash now checks static map occlusion to the nearest capsule point.
For a wall impact it biases the visibility origin 1 mm toward the incoming side
to avoid a zero-distance hit hiding all same-side victims. The blast scalar is
still measured at the actual impact. This is reconstructed server behavior,
not a native explosion-sampling implementation. Partial-cover sampling,
dynamic shields, projectile radius and original-client effects remain OPEN.

Regression: with visibility bypassed, a Pharah wall impact incorrectly reduces
an enemy behind the wall from 200 to 120 HP. With the fix it stays at 200.
An offset enemy on the incoming side still takes attenuated splash damage.
