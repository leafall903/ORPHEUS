Previous behavior
Combat._blast_impulse returned immediately for every Bot. The manual NPC had no
body physics clock. Real Concussion inputs changed no NPC position. Merely
setting Bot.velocity would still not move or collide its body.

Current host
Prepared manual NPCs with no patrol route can acquire an impulse_mover. It is the
existing character Mover using the actual body row, match collision and correct
team/FFA proxy category. It advances zero-input poses on Match ticks, with body
movement mods, capsule contacts, friction, gravity, quantization and landing.
Duplicate ticks do not advance. Movement records use its real velocity, air flags,
air ticks and gravity. Team changes invalidate the cached capsule/category.
Stun removes commanded action, preserving physical momentum. Death clears the
mover and stops the retained corpse. Respawn constructs a fresh Bot.

The actual43-row external mover runtime is required. Missing body rows do not
silently acquire the Soldier fallback for this service. The input mover SHA is
e3943bc4299d43fd5478d5f074d449a1ca70d817a10a66c36466ff3dd33de84c.
The host does not extend automatic navigation or the existing training patrol
model. A manual actor retains the physical mover at rest until death/removal;
native allocation/retirement and AI arbitration are unproven.
