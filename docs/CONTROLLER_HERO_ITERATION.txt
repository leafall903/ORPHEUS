Ownership and dependencies
SceneWorld binds a controller_heroes.Context to an already-created owner. Every
evaluation also checks the current script component's identity. An old instance
cannot borrow a replacement component's context; its failure cannot retire that
replacement. Detach, unbind and owning-component failure retire the context.
Callbacks are checked again before their results can be used. Candidate traversal
shares the script work budget, including zero and rejected catalog rows.

The API returns an owned iterator. Scalar evaluation closes it after the first
item; collection and config traversal close it on completion or exception.
Catalog data is a per-evaluation tuple snapshot. No native heap allocation or
opaque cache is retained by the Python VM. Dependency callbacks preserve selector
watches and the existing native-query poll marker. A known absent dependency hub
may be supplied as None; unknown observers remain unsupported.
