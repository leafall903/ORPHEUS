with None slots denoting absent ids. Only a query targeting that component's owner
can use this service. Foreign-entity queries retain the existing unsupported path;
no controller/body identity or missing component is invented.

unless explicit records are provided. Combat._sync_body_health supplies actual

policy, not a claim to reproduce native entity lookup or native storage allocation.
Pool values and flags participate in passive body/server snapshots without running
getters. They are not derived lazily from HUD variables during a query.
