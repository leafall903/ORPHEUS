Native order and results
- CDBDE0 checks its evaluation context and context+30 namespace before evaluating
  selector+10. Absence returns no output. Selector uses scalar/first-value entity
  conversion; absent, failed or non-entity values become entity0. There is no
  valid-entity guard before D15520's lookup, including for0 andFFFFFFFF.
- D15520 obtains VM through namespace+58 and performs VM+168 entity lookup.
  A missing target returns no output. CDBDE0 then observes environment kind0 or
  fallback kind46 when a watcher and dependency hub exist. The caller's prior
  destination survives; this differs from a successful typed Entity(0).
- A known missing component43 succeeds with Entity(0), without a component
  observation. Unknown component data remains unsupported.
- A present component is captured, observed through1B72C10 at component+18,
  then read through BD42D0. Replacing the target's component pointer in that
  observation does not replace the captured component; changing the captured
  component's relation value does affect the result. The uint32 result is typed
  Entity even if zero or another invalid identity. No second entity lookup occurs.
- Context rebinding, owner/instance retirement, target retirement and malformed
  descriptors abort after callbacks. No persistent VM/snapshot fields are added.
