Evidence boundary
-----------------
The 0079 body initializes 0033/004B/0043/0263/0266/0277/073A/08B6,
weapon manager 0015 and weapon 0776. Actual secondary commands activate
0776/st11 once; its authored ModifyHealth evaluates to 25 and loadout 00A3.
The associated st10 radius evaluates to 7 and angle field m_A30B383E to 70.
Existing TrackTargets always returns an empty payload, so no target receives
this damage without an explicit server consumer.

This patch consumes st11 activations through the ordinary Combat.command path,
reads damage/range/angle from the actual states, uses rewind target poses,
enemy selection, static occlusion and existing damage/death/health replication.
It does not replace cooldowns with raw button timers. Body retirement removes
the existing per-body activation cache.

Reconstruction assumptions: 70 is a full cone angle; angular selection uses
the capsule centre, range uses capsule surface, and sight uses the centre ray.
Those geometric choices need native comparison. This is a bounded damage
implementation, not a completed Soundwave implementation. Knockback, its
client correction and barrier/status/absorption/deflection semantics are open.
