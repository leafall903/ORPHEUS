Resource/native evidence:
01F0 node7 sets1648=15. Nodes8/11 execute STU_FF3471E9 with a vector replacement
row STU_95A10547, field m_CFEC5F76=1. The resource computes normalized horizontal
forward/right throttle direction, falling back to horizontal forward when idle,
and adds current vertical velocity. The horizontal expression subtracts the
orientation's lateral basis; double-negating this basis reverses strafing.
Node4 waits0.4s with the authored movement modifiers. Node17 emits a scalar
minimum STU_748FC65A, field m_A9561CA0=1, value5.5 on the movement scope's end.

Read-only captured104319 instructions identify the FF3471E9 runtime constructor

C32CCA..C32D22 computes desired velocity minus sampled velocity; the resulting
record is bounded to one frame by C32D67..C32DBA. D2B69D..D2B6BC supplies source
frame+1. These are static instruction observations, not a full live mover trace.
The end clamp maps through C32860 to numeric property33. Full native phase
ordering and the general velocity/property backend are not implemented here.

Implementation scope:
Only declared McCree01F0 nodes8/11/17 are handled. Unsupported rows and other
worlds still return NotImplemented. The body's existing state graph supplies
the velocity expression, duration, refill, end and cooldown; no new ability
activation or fixed dash timer is injected. The reconstructed basis/velocity

A BodyWorld list stores sampled next-frame delta/cap requests. Player posing
consumes them once before the existing Mover collision/contact step. The end
clamp currently limits horizontal speed while preserving vertical velocity;
this is a reconstruction until original phase behavior is compared. Controlled
input, authored interruption, death and retirement clear pending requests.
Duplicate commands cannot consume or apply the request again. Both VM and
server causal snapshots include the pending list.

Cooldown discovery:
Ability.can_start previously consumed a buffered press and reinserted it with
"now" every unready frame. This indefinitely refreshed a released early press,
causing a second Roll automatically at cooldown expiry. Retain the original
press until gates pass, consume only on start, and let its authored early-press
window expire. Actual command tests cover expired early presses, near-expiry
short buffering, held input, countdown and fresh recast.

hostile manual NPC capsules through the existing character contact solver.
Retained corpses stay outside this sweep. A contact that changes horizontal
velocity starts the existing owner correction stream at the contact frame.
The NPC proxy uses the standing dimensions from the body mover data. This is
a sandbox reconstruction of contact with NPCs.
