Implemented behavior
E72F6348 (CE4A60) first obtains the native namespace. A missing namespace is
a no-output failure. A known missing active environment produces Bool false
without evaluating the entity config. With an environment it subscribes to its
entity dependency, evaluates the selector through +20, converts only an Entity
or recursively the first array member, and rejects zero/invalid identities.
Other identities are resolved through the owner's complete native lookup.
An existing object yields true; known absence yields false.

0AC15F78 (CEDBD0) requires its separate instance context. It evaluates the same
typed selector but passes every resulting uint32 identity to lookup, including
zero and invalid identities. A missing object leaves the caller's destination
unchanged. An existing object without component44 successfully writes Entity(0).
An existing component44 is observed before its current possession is read.
The result remains an Entity even when its stored identity is zero or invalid.
This is the forward current-object relation, not an inversion of DB742151's
reverse primary-possessor catalog.

00707E1E (CE7660) evaluates selector m_00903303 and looks up the typed entity.
Missing lookup observes the active or fallback environment and writes Entity(0).
An existing entity without component44 also writes Entity(0). For a present
component it observes the dependency at +18 before BD4A90 reads the body ID
at +D0. Target.body_field declares that value independently of current
possession. A host that knows current possession alone still lacks this field.

D379F515 (CE7EA0) evaluates m_target before m_7826B991, then resolves the

float32 at +114. Missing owner, component or record preserves the caller's
destination. World.target_record_scalar supplies the scoped lookup, with
None for known absence and NotImplemented for an unavailable service.
Record population and native lifetime are separate from this evaluator.

9B7648C3 and 60146072 read current and maximum values through component51

Its selector field is m_801B298F, evaluated through scalar +20 then F64C20; a
missing/failed/non-entity selector becomes Entity(0) before lookup. Like the

World.entity_possessor_context delegates to entity_query_context, while hosts
may install this relation separately without enabling other entity queries.

Host interface and lifetimes
World.entity_query_context defaults to unknown. SceneWorld can bind a live
entity_queries.Context to an already-created owner. Namespace availability,
active environment availability, possession-context availability, entity lookup,
dependency hubs and component observers are explicit inputs. The host must
sample the correct native context for each use. No service is inferred from
UUID bindings, script ownership, map presence or reverse possession relations.
Lookup returns Target, None for known object absence, or remains unsupported.
Target.possession distinguishes unknown component data, known absence and a
Possession value. Mutable current values are read after observer registration.
Detach, unbind and owning-component failure retire the context. A stale failed
component cannot retire a replacement component's context.
