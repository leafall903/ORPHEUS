Executed host policy (explicit reconstruction)
- Actual hostile damage supplies mitigated, pool-clamped HP loss before the
  authored charge multipliers; armor, Breather reduction and overkill affect
  the input rather than supplying the unmitigated requested damage.
- Enemy-caused missing HP is tracked as Vitals.ult_healing_deficit. Every heal
  drains it; only actual eligible self healing earns Breather charge. Self and
  environment damage and overhealing do not grant healing points.
- Dead/retired owners and running ultimates reject gains. Suppressed healing
  is consumed rather than deferred for later charge. Numeric ult_seconds=0
  disables passive gain only; positive values remain time-to-full sandbox
  overrides. Default None uses the Roadhog graph, other heroes retain60s.
- When the authored Wait is inactive, accepted command-frame time accumulates
  to the authored interval. An active Wait owns its own cadence and the host
  fallback does not add a second clock. This is not native game-server timing.
- Passive remainder and healing deficit are causal stored state. Body VM,
  command-trace and full server snapshots retain the relevant fields. Replay
  headers accept None and finite numeric charge policies.

Acceptance boundaries
- Tests use actual firing/casts and actual player/NPC pools. A high-health
  fixture permits full-cost acquisition and Whole Hog duration; it does not
  change retail hero health. Authored multipliers and zero overrides are tested.
- Native game-message/tag/mode eligibility, shielding exclusions, native time
  under arbitrary input gaps, victim-specific passive modifiers and every
  Roadhog-specific passive remain unaccepted. Full static acceptance stays open.
- No original-client session, charge HUD, sound or effects acceptance is claimed.
