block keys that logical list by 218, rather than exposing an allocation pointer
or capacity. Every refresh replaces it. Vector xyz components are retained;
native padding is not treated as an authored fourth component. All four angle
inputs default to zero. The original radians constant at 260FC98 is f32

or failed scalar config retains its supplied default; a successful null casts
to zero. First-array casts do not search later members for a successful value.

The primitive passes its State to scalar and iterator config evaluation. Active
dynamic reads therefore keep existing VM watcher and work-budget semantics;
inactive callbacks do not acquire active watches. Native per-frame invocation
and effect lifetime remain outside this helper. Unknown configs remain strict.
