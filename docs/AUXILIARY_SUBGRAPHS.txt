Implemented primitive
ScopedSubgraph models the custom interface methods. State.on_created runs
after instance insertion, before first begin. SceneWorld.set_subgraph_scopes
declares a per-entity scopes.Registry or known no registration service (None).
A bound but undeclared entity remains unknown and strict creation stops there.
Legacy body prediction keeps its previous passive policy.

Registry registration stores the object and runs no graph code. enter/exit
explicitly invoke the verified callbacks and share the component's work/follow
budgets. They allow an inactive parent, preserve deferred child begin events,
and exit aborts listed child states and drops their begins at the current time.
No callback is inferred from a parent begin, finish, abort or frame update.
Local allocation order is retained; native authoritative dispatch order is open.

Object release unregisters the interface without running more authored plugs.
Component.destroy releases even never-begun states after ending allocated states.
Entity retirement and strict VM failure clear registrations. A retired instance
or reused ID cannot dispatch an old object. Replacing a declared service requires
retiring the entity first. These registry cleanup rules protect the local host;
they are not a claim to reproduce an unknown native server callback protocol.

The ScopedSubgraph reference field is covered by read-only body VM storage when
it is None under legacy body policy. SceneWorld and Registry-backed mission
storage/restoration remain unsupported. No new Component persistent field is added.
