Damage clock:
StateModifyHealth15/25 targets m_FA3ECC43=#536. The1157 graph supplies the

Victim control and lifetime:
Combat.pins records source body -> victim body separately from timed stuns.
The authored pin scope23 retains control through the delay between contact and
continuous damage. Entry releases held input and stops running abilities via
their existing exit paths, including Deadeye and its owned target effects.
Controlled player input suppresses movement/actions/attacks while look/gravity
continue under the existing control policy. This is server control, not a
complete native pin/camera/QTE/effect implementation. Independent Flashbang
deadlines survive pin release.

Pin/health scope exit, manual stop, source stun/death/removal, target death/body
retirement, target/geometry/team loss and script failure release control.
Retained NPC corpses remain until explicit removal. The frame-end bridge removes
control when scope23 no longer exists. BotWorld match/target bindings, health
clock and Combat.pins are included in their enclosing causal snapshots.

Recovery difference:
Release Anim31 currently has no resolved animation-asset duration and can retain
its stack indefinitely. A new explicit manual engagement interrupts that state
through its authored end plugs before starting the new target. No fabricated
animation duration is installed. Original release duration, cooldown, animation
interruptibility and the native pin lifecycle remain open.

After a target leaves, the sandbox can select a replacement while the previous
pin is still bound. The bridge releases the old input for one combat update
before binding the new body. This gives the old scope's authored exits time to
start Anim31 before the new binding interrupts it. The real Rialto resource
probe reproduces the stuck release before this change and measures the new
target taking 25 damage two frames after the first player leaves.
