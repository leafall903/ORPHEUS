6. Evaluate F61726FE with false default. False returns true. True requires known

Context contract and limits
Target declares uint32 entity identity, component25 FilterBits or known absence,
component97 presence, component76 Tags or known absence, registry callback or
known absence, and optional Groups or known absence. Context declares native
owner pointer, relationship service and observation callbacks. Unknown services
fault when needed. Context rebinding/retirement, target retirement and invalid
instance lifetimes abort after callbacks, including empty collecting configs.
No persistent VM fields or snapshot schema additions are introduced.
