Implementation and ownership
nodes.EntityControl implements strict begin/cleanup registration, cache refresh,
dependency/tick updates and the inherited link payload. entity_control.Context
requires explicit target component, capability/permission, distance, extra query and
entity/model consumers. Each consumed boolean service must return a real bool.
Known absent context/component and unknown service remain separate. Permissive
legacy bodies keep their passive policy. SceneWorld binds contexts explicitly,
retires dependent bindings with entities/failure, and rejects another world's
component. Callback owner retirement faults before further consumer calls.
Read-only VM observations include the seven persistent cached fields.
